# Loan Approval Prediction Using Machine Learning Algorithms

> A research paper submitted in partial fulfillment of the B.E. degree in Computer Science and Engineering, Chitkara University, Punjab, India.

---

## 📄 Abstract

This research paper focuses on predicting loan approval decisions using Machine Learning algorithms. Traditional loan approval systems are time-consuming and prone to human bias, making automated prediction systems highly important in modern banking environments.

The study presents a comparative analysis of three supervised machine learning algorithms — Logistic Regression, K-Nearest Neighbors (KNN), and Naive Bayes — using historical loan applicant data. Various preprocessing techniques such as missing value handling, categorical encoding, and feature scaling were applied to improve model performance.

Experimental results show that Logistic Regression achieved the best overall performance due to its balanced accuracy, interpretability, and suitability for binary classification problems. The research demonstrates how machine learning can improve efficiency, scalability, and reliability in financial decision-making systems.

## 📊 Research Methodology

- Historical loan application dataset used for training and testing
- Missing values handled using mean/mode imputation
- Label Encoding and One-Hot Encoding applied for categorical data
- Feature Scaling performed for improved model performance
- Dataset split into training and testing sets using 80:20 ratio
- Models evaluated using Accuracy, Precision, Recall, and F1-Score

---

## 📈 Key Findings

1. Logistic Regression achieved the best overall performance among all evaluated algorithms.
2. KNN successfully captured non-linear feature relationships but required higher computation.
3. Naive Bayes provided fast predictions with moderate accuracy.
4. Machine learning significantly improves loan approval efficiency and reduces manual effort.
5. Proper preprocessing techniques greatly enhance prediction performance.
